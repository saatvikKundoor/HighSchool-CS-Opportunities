# Contributing Guidelines

This is a guideline and helpful resource on how to contribute to Highschool-CS-Opportunities. Thank you to anyone who contributes, whether that be adding opportunities, fixing issues, or add new features! 

## Adding an Opportunity (any section)

This repo uses github's native markdown format for tables, which consists of multiple columns using `|`. To add a new opportunity, simple add another row at the bottom of the section you want to add to. 

Here are some helpful rules/tips:

- Bold the names of the opportunity using `**` (Note: You must use `**` before and after the words you want bolded)
- Try to keep descriptions to be 1-2 sentences long. Descriptions don't need to cover anything, they just need to provide a general sense; people can click the links for more info
- Internship section only: refer to the legend for how to signify an internship costs money, is unpaid, or pays you. 

## Github Commit Practices

To keep commit history clean and understandable, here are a few rules to keep in mind when writing commit messages:

- For adding an opportunity, commit messages should follow this format "Add `Opportunity Name` to `Section`"
- For added a new feature, simply describe the feature and where it is being added. For example: "Add Date section to Awards"
- For fixing an issue, simply describe the fix. For example: "Fixed typo in Lockheed Martin entry"

**Have fun contributing!**
